# LSR-2027 evaluation protocol

**Development preview, 24 November 2026.** The pilot code implements image fidelity for T1 and T2 and scalar BV/TV agreement for T3. The structural endpoints below are candidate formal rules. Their parameter qualification and release are prerequisites for formal ranking.

## Tasks and outputs

| Track | Submitted output and organizer reference | Pilot comparison and reporting | Formal primary endpoint under development |
| --- | --- | --- | --- |
| T1 · Standard CT to Micro-PCCT | Reconstruct each required CT protocol on the paired 105 µm Micro-PCCT grid of the same ex vivo vertebra. | PSNR descending. Report PSNR, 3D SSIM, MAE, RMSE and signed bias. | Local three-dimensional BV/TV MAE and spatial bone F1 with a physical tolerance. Use a combined rank if both qualify. |
| T2 · Clinical-grade PCCT upsampling | Reconstruct the finer sampling grid from a coarser reconstruction of the same ex vivo vertebra, preferably from the same acquisition. | PSNR descending. Report the same image metrics as T1 with a T2-specific reference and manifest. | Apparent 3D trabecular separation (Tb.Sp) error in mm, conditional on repeatability, paired registration, and effective resolution. |
| T3 · Quantitative bone biomarker | Predict one BV/TV percentage per vertebra from a prespecified routine CT protocol. The reference is the organizer's Micro-PCCT-derived measurement in a predefined cancellous volume of interest (VOI). | BV/TV MAE ascending. Report signed bias and specimen count. | The same scalar ranking rule after reference qualification. Apparent Tb.Sp may be reported separately after qualification. |

T1 uses paired cross-scanner images. T2 uses the clinically available scanner to compare reconstructions at two sampling scales. T3 quantifies agreement for a scalar bone biomarker relevant to osteoporosis research. The experimental unit is an ex vivo vertebra. The source LumbarSR study describes the public paired CT and Micro-PCCT dataset and the existing baselines. [Scientific Data article](https://doi.org/10.1038/s41597-026-07748-5) · [Public dataset](https://doi.org/10.5281/zenodo.19404387)

PSNR is the comparison metric for the T1/T2 image-fidelity preview. The shared organizer sandbox reports scores for each SR task and retains BV/TV MAE as its global display sort. The pilot uses one sample submission per phase, so comparative SR ranking was not exercised there.

## Image fidelity for T1 and T2

The organizer fixes the target grid, valid paired coverage, and the three-dimensional VOI before scoring. Both images use the same voxel coordinates. At scoring time the executable checks the shape, spatial unit code, and voxel-to-world transform with an absolute per-coefficient tolerance of 0.0001. The official acquisition and registration QC must independently assess alignment in the trabecular VOI.

| Metric | Per-case computation | Interpretation |
| --- | --- | --- |
| Intensity MAE | Mean of `abs(prediction − reference)` over masked voxels after NIfTI intensity scaling. | Typical magnitude of intensity disagreement. |
| Intensity RMSE | Square root of the mean squared error over the same voxels. | More sensitive to large intensity errors. |
| Signed intensity bias | Mean of `prediction − reference` over the same voxels. Use HU when that intensity scale is verified. | Detects systematic under- or overestimation. Report separately from absolute errors. |
| PSNR (dB) | `20 log10((high − low) / RMSE)` using the masked RMSE and one fixed intensity range for the track. Cap at 120 dB including exact matches for a finite output. | Conventional scale-normalized image fidelity. A single window and mask rule support within-track comparisons. |
| 3D SSIM | Clip both images to the fixed range and shift by its lower bound. For every uniform 7 × 7 × 7 voxel window entirely inside the mask, compute SSIM from local means, sample variances and covariance. Use constants `(0.01 × range)²` and `(0.03 × range)²`. Mean over eligible windows. | Local agreement of image intensity statistics and structure at the selected scale. The mask excludes border and background contributions. Report voxel spacing so the physical window span can be interpreted. |

MAE, RMSE and bias use the original scaled intensities within the mask. PSNR uses the same RMSE. The preview manifest uses a 3,000-unit dynamic range where specified by the pilot data. The final bounds are to be fixed independently for each track on public development evidence. The SSIM calculation follows the original local luminance and covariance formulation using the explicitly defined uniform three-dimensional window here. [Wang et al., Image Quality Assessment](https://ece.uwaterloo.ca/~z70wang/publications/ssim.pdf)

Average each case measure over the prespecified protocol volumes within each specimen, then average the specimen values with equal weight. Keep one case per specimen and protocol and report each protocol stratum as a secondary analysis. A submission with a missing or invalid volume fails evaluation. Image metrics assess reconstruction fidelity against a paired reference. The structural endpoints address preservation of bone volume, location and trabecular separation.

## Structural endpoint qualification

**T1 local BV/TV and location.** Define the cancellous VOI before comparing images and exclude cortical shell, endplates and regions without registered coverage. Partition it into fixed physical subregions with a published minimum valid coverage, grid origin and edge rule. Apply the same validated 3D segmentation procedure to the reference and prediction in the target domain. For each eligible subregion compute `100 × bone voxels / valid VOI voxels` in each image and use the mean absolute difference in percentage points. For spatial F1, precision is the share of predicted bone voxels within the specified Euclidean distance of reference bone. Recall exchanges prediction and reference. F1 is their harmonic mean, and a valid empty prediction has F1 zero where reference bone exists. Set the distance tolerance on the public development set from measured local registration error and examine sensitivity down to zero tolerance.

If both T1 endpoints qualify, rank teams by the average of their ranks for specimen-averaged local BV/TV MAE (ascending) and tolerance F1 (descending), giving tied scores average ranks. A tie in the combined rank uses higher tolerance F1, with equal rank if still tied. If the location metric cannot be supported at the validated reference scale, freeze the qualified regional BV/TV endpoint alone before private evaluation and report the spatial metric as exploratory.

**T2 apparent Tb.Sp.** Check the fine reconstruction's sampling geometry, reconstruction kernel, energy, effective resolution and repeatability in the expected cancellous VOI. Prefer coarse and fine reconstructions from the same acquisition. The candidate measure uses a direct 3D local-size estimate in the marrow space, in mm. Measure the maximal inscribed sphere containing each eligible voxel and summarize within the fixed VOI after an explicit boundary treatment. Compare mean apparent Tb.Sp between reference and prediction using absolute error per specimen. Freeze segmentation and measurement software, background handling, VOI boundaries and repeatability limits for the clinical PCCT domain. The measured separation depends on that domain's effective resolution. If qualification fails, preregister a supported structural fallback on development evidence or report T2 as feasibility only. [Hildebrand and Rüegsegger, 3D local thickness method](https://doi.org/10.1046/j.1365-2818.1997.1340694.x) · [Hildebrand et al., human cancellous bone morphometry](https://doi.org/10.1359/jbmr.1999.14.7.1167)

**T3 scalar BV/TV.** Select a fixed 3D cancellous VOI and derive the reference percentage as `100 × bone volume / valid VOI volume` using a qualified reference segmentation. A prediction of 20% for a reference of 18% contributes an absolute error of 2 percentage points and signed error of +2 percentage points. Return one row per specimen and compute specimen-level mean absolute error and signed bias. Use the same eligible specimens and reference VOIs to compare a development-set median, development-fitted routine CT attenuation regression, direct learning and SR followed by fixed quantification. T1's spatial F1 evaluates the position of predicted bone. [3D morphometry methods in human cancellous bone](https://doi.org/10.1359/jbmr.1999.14.7.1167)

For T3, apparent Tb.Sp in mm can add information on trabecular spacing when the reference scale and repeatability support it. Report its error separately from the ranked BV/TV score. Tb.Th and Tb.N remain exploratory. Routine CT attenuation is an input to a baseline model. Quantified mineral density requires a calibrated reference and osteoporosis screening requires a clinical reference cohort. [Micro-CT resolution sensitivity study](https://doi.org/10.1016/j.bone.2004.09.007)

Validate structural scores on the public development data using interpolation and reproducible learned baselines, threshold sensitivity, registration perturbations, added blur, controlled shifts, and structural perturbations that preserve total bone volume. Document the eligible VOI, excluded cases, physical resolution and reliability of the reference. Use the higher-resolution Micro-PCCT reconstructions where available to assess measurement sensitivity to sampling. A repeat scan, calibrated phantom or independent higher-resolution reference can assess measurement trueness. Publish the frozen structural scoring code, data specification and version before using formal private scores for ranking.

## Phase boundaries and reporting

- Assign specimens across development, A and B globally, including all protocols, devices, reconstructions, patches and derived labels. Use donor-level splits when linkage is available. The split unit is never a slice or patch. The T2 formal counts depend on verified paired specimens.
- Phase A gives limited aggregate feedback. Phase B evaluates a frozen submission on a separate split. Keep references scoped to scoring and verify A/B input separation with phase-specific manifests before formal data enter the system.
- Report sample sizes and separate results by track, phase and relevant protocol strata. On qualifying private sets report specimen-level or donor-cluster paired uncertainty and rank stability. Five metrics on one phantom or one public specimen provide functional checks. The formal benchmark requires additional independent specimens. [Maier-Hein et al., sensitivity of challenge rankings](https://doi.org/10.1038/s41467-018-07619-7)
